Day 1 - Question 1: Customer Order Analysis
Difficulty: Easy-Medium
Topics: JOIN, WHERE, GROUP BY, HAVING, COUNT, SUM, ORDER BY

Question
--------
You have two tables:

Table 1: customers

+-------------+-------+
| customer_id | name  |
+-------------+-------+
| 1           | Asha  |
| 2           | Kiran |
| 3           | Meera |
| 4           | Rahul |
| 5           | Diya  |
+-------------+-------+

Table 2: orders

+----------+-------------+--------+-----------+
| order_id | customer_id | amount | status    |
+----------+-------------+--------+-----------+
| 101      | 1           | 1200   | Delivered |
| 102      | 1           | 900    | Cancelled |
| 103      | 1           | 1600   | Delivered |
| 104      | 2           | 900    | Delivered |
| 105      | 2           | 700    | Delivered |
| 106      | 3           | 2500   | Delivered |
| 107      | 4           | 600    | Delivered |
| 108      | 4           | 500    | Delivered |
| 109      | 5           | 400    | Cancelled |
+----------+-------------+--------+-----------+

Task:
Find customers who have at least 2 delivered orders, considering only
orders where amount >= 500.

Display:
- customer_name
- delivered_orders
- total_amount

Sort by highest total_amount first.

Expected Output
---------------
+---------------+------------------+--------------+
| customer_name | delivered_orders | total_amount |
+---------------+------------------+--------------+
| Asha          | 2                | 2800         |
| Kiran         | 2                | 1600         |
| Rahul         | 2                | 1100         |
+---------------+------------------+--------------+

My SQL Query
------------
SELECT c.name as customer_name, COUNT(*) AS delivered_orders, SUM(o.amount) AS total_amount
FROM orders o
LEFT JOIN customers c ON o.customer_id = c.customer_id
WHERE o.status = 'Delivered' AND o.amount >= 500
GROUP BY c.name, c.customer_id
HAVING COUNT(*) >= 2
ORDER BY SUM(o.amount) DESC

Day 1 - Question 2: Employee Salary Update
Difficulty: Easy-Medium
Topics: UPDATE, SET, CASE, WHERE

Question
--------
You have the following employees table:

+--------+-------+------------+--------+------------+
| emp_id | name  | department | salary | experience |
+--------+-------+------------+--------+------------+
| 1      | Rahul | Backend    | 50000  | 2          |
| 2      | Priya | Backend    | 80000  | 5          |
| 3      | Amit  | QA         | 40000  | 1          |
| 4      | Sneha | Backend    | 60000  | 3          |
| 5      | Karan | QA         | 70000  | 4          |
| 6      | Riya  | DevOps     | 90000  | 6          |
+--------+-------+------------+--------+------------+

Task:
Write one SQL UPDATE statement that:
1. Increases salary by 20% for Backend employees having 3 or more years of experience.
2. Increases salary by 10% for Backend employees having less than 3 years of experience.
3. Does not modify employees from other departments.
4. Performs the entire update using one SQL statement.

Expected Table After Update
---------------------------
+-------+------------+--------+
| name  | department | salary |
+-------+------------+--------+
| Rahul | Backend    | 55000  |
| Priya | Backend    | 96000  |
| Amit  | QA         | 40000  |
| Sneha | Backend    | 72000  |
| Karan | QA         | 70000  |
| Riya  | DevOps     | 90000  |
+-------+------------+--------+

My SQL Query
------------
UPDATE employees 
SET salary = CASE 
       WHEN experience >= 3 THEN salary + (salary * 0.2)
       ELSE salary + (salary * 0.1)
END
WHERE department = 'Backend'
